# 🚀 AEO & SEO Optimization Toolkit

A specialized Python framework designed to optimize content visibility and brand presence across AI Answer Engines (AEO) such as ChatGPT, Perplexity, and Claude, alongside traditional Search Engine Optimization (SEO).

## ✨ Key Features
* **AI Knowledge Extraction:** Analyzes how LLMs index and summarize specific brand keywords.
* **Schema & Structured Data Generator:** Automated JSON-LD generator for enhanced search engine entity recognition.
* **Content Relevance Scoring:** Evaluates content against target queries for maximum AI response inclusion.
* **Automated Audit Reports:** Generates actionable insight reports for digital marketing strategies.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** BeautifulSoup4, Requests, Pydantic
* **Format:** JSON-LD / Markdown
